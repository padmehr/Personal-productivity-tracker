# Personal Progress Tracker

A personal productivity application built with Python to help track work sessions, breaks, and daily progress.

## Features

- Pomodoro timer with Start and Pause functionality
- Automatic switching between Work and Break sessions
- Long break after every 4 completed work sessions
- Countdown timer
- Completed session counter
- Current mode display (Work, Rest, Longrest)
- Timer Configuration menu

## Technologies

- Python
- Tkinter

## How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd Personal-Progress-Tracker
```

3. Run the application:

```bash
python main.py
```
