# Pomodoro Timer

A simple Pomodoro Timer built with Python and Tkinter.

## Features
- Start and Pause timer
- Automatic switching between Work and Break sessions
- Long break after every 4 completed work sessions
- Countdown timer

## Technologies
- Python
- Tkinter

## Status
Currently under development. More features will be added.

## How to Run
```bash
python main.py
```
